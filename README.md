# Word Quest 🎯

A playful, kid-friendly crossword game for building vocabulary — built for a 6-year-old explorer.

## Features

- 🎨 **8 topics**: Animals, Space, Food, Sports, Colors & Shapes, Superheroes, World, Tech & Trendy
- 🎚️ **3 difficulty levels**: Easy (3–4 letter words), Medium (4–6), Hard (5–8)
- 🧩 **Procedurally generated crosswords** — a new puzzle every play
- 💡 **3-tier hint system**: reveal first letter → reveal half → show kid-friendly explanation
- ⏱️ **Toggle-able timer** with time bonus on completion
- ⭐ **Scoring** rewards speed and penalizes hints/reveals
- 🎉 **Confetti victory** screen
- 📱 **Mobile-friendly** touch targets

## Stack

- Next.js 16 (App Router) + React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion (animations)
- canvas-confetti (victory celebration)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to `main`; Vercel builds & deploys automatically.
